# Доступ для проверки

После локального запуска `python manage.py seed_demo`:

| Логин | Пароль по умолчанию в локальном режиме | Роль |
| --- | --- | --- |
| student1 | PracticeDemo2026! | Владелец своих заметок |
| student2 | PracticeDemo2026! | Второй пользователь для проверки изоляции |
| auditor | PracticeDemo2026! | Чтение всех заметок без изменений |

Вход: http://127.0.0.1:8000/accounts/login/ . Создайте запись под student1, выйдите и войдите под student2: запись первого пользователя отсутствует. Под auditor видны записи обоих пользователей, но операции изменения запрещены сервером.

Это демонстрационные аккаунты, их пароли предназначены для передачи проверяющему. Не используйте их для личных данных. Если `DEMO_PASSWORD` был задан при первом создании, действует указанное вами значение. Повторный seed_demo не сбрасывает существующие пароли.

Суперпользователь создаётся владельцем проекта отдельно командой `createsuperuser`; его пароль в документацию и репозиторий не записывается.
