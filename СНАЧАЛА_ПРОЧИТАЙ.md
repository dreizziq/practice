# Что делать с готовым пакетом

1. **Посмотреть проект:** в PowerShell из этой папки выполнить `powershell -ExecutionPolicy Bypass -File .\start.ps1`. Открыть http://127.0.0.1:8000/.
2. **Загрузить исходники** в публичный GitHub-репозиторий. На GitHub должны лежать файлы проекта, а не ZIP. Инструкция: [docs/DEPLOY.md](docs/DEPLOY.md).
3. **Разместить сайт:** в Render создать Blueprint из репозитория; конфигурация `render.yaml` готова.
4. **Заполнить `submission.json`:** ФИО, группа, учебное заведение, руководитель, сроки практики, город, ссылки на GitHub и деплой. Для Code Climate/Qlty добавить только реальные данные анализа.
5. **Обновить отчёт и README:** установить `requirements-report.txt` в окружение и выполнить `python tools/build_submission.py` этим же Python. Подробные команды приведены в [инструкции](docs/DEPLOY.md).
6. **Сдать:** публичные ссылки, файл `output/pdf/practice-report.pdf`, демонстрацию `docs/demo.gif`. Перед сдачей пройти [чек-лист](docs/BEFORE_SUBMISSION.md).

PDF содержит 7 разделов практической части, схемы, таблицу соответствия и вывод. Редактируемый текст — `docs/REPORT.md`. В присланном гайде нет официального шаблона бланков: если он требуется, используйте шаблон учебного заведения для официальной части.

GIF записывает основной сценарий создания и изменения заметки и длится 24,5 секунды. Все 8 локальных тестов проходят. Внешний бейдж A/B пока не получен; локальные тесты не заменяют его.
